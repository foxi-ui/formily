# 实现表单布局

表单布局主要是使用[@formily/antd](https://formilyjs-v2.bugduo.com/antd/zh-CN) 或 [@formily/next](https://formilyjs-v2.bugduo.com/next/zh-CN) 中的：

- [FormLayout](https://formilyjs-v2.bugduo.com/antd/zh-CN/components/form-layout) 组件
- [FormItem](https://formilyjs-v2.bugduo.com/antd/zh-CN/components/form-item) 组件
- [FormGrid](https://formilyjs-v2.bugduo.com/antd/zh-CN/components/form-grid) 组件
- [Space](https://formilyjs-v2.bugduo.com/antd/zh-CN/components/space) 组件

这 4 个组件基本上能解决所有复杂表单布局场景，我们只需要灵活的组合使用这几个组件即可。
