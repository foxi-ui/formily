# Form Layout

The form layout mainly uses [@formily/antd](https://formilyjs-v2.bugduo.com/antd) or [@formily/next](https://formilyjs-v2.bugduo.com/next):

- [FormLayout](https://formilyjs-v2.bugduo.com/antd/components/form-layout) Component
- [FormItem](https://formilyjs-v2.bugduo.com/antd/components/form-item) Component
- [FormGrid](https://formilyjs-v2.bugduo.com/antd/components/form-grid) Component
- [Space](https://formilyjs-v2.bugduo.com/antd/components/space) Component

These 4 components can basically solve all complex form layout scenarios, we only need to flexibly combine these components.
